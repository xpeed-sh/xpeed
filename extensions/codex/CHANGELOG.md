# Changelog — Codex

La versión corresponde al adaptador, independiente de la versión de Xpeed y del runtime oficial de Codex. Los cambios del chat dibujado por Xpeed se registran en el changelog de Xpeed.

## Sin publicar

## 0.3.2 — 2026-10-15

- Logo vectorial y captura del flujo de conversación incluidos en el repositorio y en la ficha Markdown.
- Documentación organizada para publicar el proyecto Git independiente, con VERSION y este changelog.

## 0.3.1 — 2026-10-09

- Continuación de conversaciones guardadas mediante el hilo original del proveedor (`thread/resume`).
- Integración con el host que conserva chats, títulos, borradores, modelo y preferencia de acceso; las autorizaciones de sesiones no se restauran tras reiniciar.

## 0.3.0 — 2026-10-09

- Integración con el panel independiente de Codex.
- Herramientas para ejecutar comandos en la consola visible y leer la pantalla de las sesiones autorizadas.

## 0.2.2 — 2026-10-09

- Compatibilidad verificada con codex-cli 0.162.0-alpha.17.2, además de 0.162.0-alpha.2.
- Validación explícita del runtime y pruebas con herramientas de sesiones.

## 0.2.1 — 2026-10-09

- Corregido «code-mode host is disabled», habilitando el despacho de herramientas del host y conservando las restricciones del proveedor.

## 0.2.0 — 2026-10-09

- Adaptador app-server con inicio de sesión oficial de ChatGPT en un perfil separado.
- Herramientas para sesiones seleccionadas, aprobaciones, lectura y cambios de archivos, interrupción y límites de ejecución.

## 0.1.1 — 2026-10-09

- Interfaz, manifiesto y documentación en inglés y español.

## 0.1.0 — 2026-10-08

- Primer adaptador opcional: detección del runtime local, inicio de sesión, modelos y chat.
